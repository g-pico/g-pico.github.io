## MODIFIED Requirements

### Requirement: Home page tables support tab switching
The home page SHALL allow visitors to switch between news, technical documents, and useful links without leaving the page. The current baseline activates tab content through the existing tab interaction handlers.

#### Scenario: Visitor selects technical documents
- **WHEN** a visitor activates the technical documents tab
- **THEN** the technical documents table becomes the active visible table

### Requirement: Resource links open external references safely
Technical document and useful-link rows generated by `i18n.js` SHALL render external anchors with `target="_blank"` and `rel="noopener"`. News rows that link to local `news_single.html` pages SHALL remain same-tab internal links.

#### Scenario: Visitor opens an external resource
- **WHEN** a visitor clicks an external technical document or useful link
- **THEN** the link opens in a new tab with opener isolation

#### Scenario: Visitor opens an internal news item
- **WHEN** a visitor clicks a local news item link
- **THEN** the browser navigates to the matching `news_single.html?news={id}` page in the current tab
